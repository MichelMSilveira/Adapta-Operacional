# Adapta Operacional — Projeto Jurandi

Repositório de discovery e estruturação de requisitos para um futuro sistema operacional aderente à rotina do cliente Jurandi.

Este projeto ainda não é uma aplicação pronta. Seu objetivo atual é compreender a operação real, separar fatos de hipóteses e criar uma base segura para decisões futuras de produto, processo e tecnologia.

## Princípios

- a operação do cliente é a fonte principal de verdade;
- fatos confirmados, inferências, hipóteses e sugestões permanecem separados;
- processos da Proelium não são importados automaticamente;
- nenhuma funcionalidade ou tecnologia é definida antes de haver requisitos suficientes;
- cada decisão importante deve preservar o contexto para as próximas etapas.

## Estado atual

O projeto está na fase de discovery. Requisitos, arquitetura, stack, implementação, validação e produção ainda não foram consolidados.

## Como contribuir com segurança

Antes de alterar o projeto, leia [`AGENTS.md`](AGENTS.md), [`PROJECT.md`](PROJECT.md) e [`docs/STATUS.md`](docs/STATUS.md). Registre novas informações como confirmadas somente quando vierem do cliente ou de material validado por ele.

Não versionar senhas, tokens, chaves, dados pessoais desnecessários ou documentos privados.
