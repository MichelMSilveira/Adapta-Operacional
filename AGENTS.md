# Regras de IA - Projeto Jurandi

## Regra principal
Este projeto deve ser construido a partir das informacoes reais fornecidas pelo cliente Jurandi. Nao importar processos, regras ou estruturas da Proelium sem validacao explicita.

## Inicio de tarefa
1. Ler `PROJECT.md`.
2. Ler `docs/STATUS.md`.
3. Consultar `docs/SESSION.md` se houver continuidade pendente.
4. Ler apenas os arquivos necessarios para a tarefa atual.

## Confiabilidade
- Diferenciar CONFIRMADO, INFERENCIA, HIPOTESE e SUGESTAO.
- Nao inventar funcionalidades, regras ou processos.
- Registrar duvidas materiais como pendencias em `docs/REQUIREMENTS.md`.
- Quando houver conflito entre informacoes, registrar o conflito e aguardar validacao.

## Implementacao
- Nao definir stack definitiva antes de requisitos suficientes.
- Fazer mudancas pequenas, justificadas e reversiveis.
- Preservar documentacao de decisoes relevantes.
- Atualizar `docs/STATUS.md` ao concluir blocos significativos.

## Seguranca
- Nunca versionar senhas, tokens, chaves ou dados sensiveis.
- Exigir autorizacao explicita para operacoes destrutivas ou irreversiveis.
